# Task Manager with Pomodoro Timer

A modern task management application with integrated Pomodoro timer functionality. Built with HTML, CSS, and JavaScript, using Firebase for backend services.

## Features

- Task Management
  - Create, edit, and delete tasks
  - Set priorities and due dates
  - Add subtasks and track progress
  - Drag and drop task organization

- Pomodoro Timer
  - Customizable work/break sessions
  - Task-specific time tracking
  - Visual progress indicators
  - Notification system
  - Draggable and resizable interface

- Time Analytics
  - Track time spent on tasks
  - View productivity statistics
  - Analyze work patterns
  - Visual data representation

- User Interface
  - Responsive design
  - Dark/Light mode
  - Modern and intuitive layout
  - Mobile-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Firebase (Authentication, Firestore)
- Chart.js for analytics
- Font Awesome for icons

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Grandson-tech/Task-manager.git
   ```

2. Set up Firebase:
   - Create a Firebase project
   - Enable Authentication and Firestore
   - Add your Firebase configuration to `js/firebase-config.js`

3. Open `index.html` in your browser or use a local server
